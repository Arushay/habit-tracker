# Habit Tracker

Track your daily habits and never break the chain.

## Features

- Add new habits
- Click habit name to mark complete for today
- Automatic streak counter (🔥 shows consecutive days)
- Statistics dashboard (total habits, completed today, best streak)
- All data saved in your browser

## Technologies Used

- Vanilla JavaScript
- HTML5
- CSS3
- LocalStorage API

## How to Use

1. Download or clone this repository
2. Open index.html in any browser
3. Add your first habit (e.g., "Morning Run", "Read 30 min")
4. Click the habit name each day when you complete it
5. Watch your streak grow!
